# `nature-research-partner` 技能

[English](README_EN.md)

`nature-research-partner` 是一个 Scientific Discovery Partner，用于把片面的灵感、异常现象和未成熟研究方向逐步转化为可证伪、可追溯、可实验验证并能持续更新的论文级科学问题。

## 适合用它做什么

- 和用户反复讨论一个突然出现的科研灵感，而不是立即替它补完整故事。
- 用数学或可操作化语言明确系统边界、变量、约束、目标、baseline 和评价标准。
- 从应用问题中逼出真正的科学矛盾、主导变量、技术失效原因和关键未知。
- 在想法被逼清到“可检索问题”后，先执行文献证据门槛，再建立“机制锚点 + SOTA + 方法证据 + 反例 + 目标论文”的五类文献坐标。
- 构建竞争假设、区分性预测、死亡条件和 reviewer 式反证审查。
- 把核心 claim、机制、实验、测量、统计判据和结论统一到一套证据架构里。
- 新数据或新文献出现后更新假设状态、证据账本、研究决策和下一步实验。
- 判断一个方向是值得继续、需要收窄、证据不足，还是应当停止投入。

## 典型请求

- “我突然想到一个研究点，你先和我把问题逼清楚，不要马上给方案。”
- “把这个想法严格形式化，然后找真正的科学矛盾。”
- “帮我建立这项研究的 5 类锚点文献坐标。”
- “站在最强反方，把我的创新点尽量推翻。”
- “哪些实验最能区分这几个机制，而不是单纯多做表征？”
- “这是最新实验数据，更新我们之前的假设和下一步计划。”

## 你需要提供

- 灵感来源、异常现象、初步数据、文献、研究对象或已有项目设想中的任意一种即可。
- 已知的实验条件、设备、时间、预算或不能改变的现实约束，若有则提供。
- 目标可以很模糊；技能会先区分已知、推断和未知，再逐步收紧问题。

## 产出

- Research Contract：系统、变量、约束、目标、baseline 和证据标准。
- Scientific contradiction：真正需要解决的科学矛盾和可回答问题。
- Literature Evidence Brief：3–5 篇高信息量锚点、最强 baseline、支持/反驳/未决判断，以及文献证据如何改变初始想法。
- Literature Coordinate：五类锚点论文及其证据边界。
- Hypothesis Ledger：候选机制、竞争解释、预测、反证和状态。
- Evidence Ledger：claim 与直接/相邻/推断证据的映射。
- Decision Log：为什么继续、收窄、转向或停止，以及什么结果会推翻当前决定。
- Master Framework：可持续迭代的论文级“挑战—机制—预测—实验—证据—claim”总框架。

## 工作方式

提供 `explore`、`challenge`、`design` 和 `update` 四种模式。`explore` 默认先用少量高价值追问把灵感收紧为可检索的科学问题，随后立即执行文献证据门槛；先返回 Literature Evidence Brief 并与用户讨论“哪些原判断被支持、削弱或改写”，再进入竞争假设、反证和证据化实验设计。新证据到来后重新更新整个研究状态。

## 边界

- 不会因为用户偏爱某个解释就默认它成立。
- 不会为了显得严谨而给未知问题强行套公式或虚构精确分数。
- 不会在可检索外部证据时仅凭模型记忆判断 SOTA、创新性、机制先例或方法有效性。
- 不会用“没有搜到文献”证明“首次”或“创新”。
- 不会把相关性、性能提升或单一表征直接升级为机制证明。
- 不会把论文写作和图件包装当成尚未解决的科学问题的替代品。

## 相关技能

- `nature-academic-search`：文献检索、搜索边界和元数据核验。
- `nature-reader` / `nature-paper-card`：锚点论文全文阅读与 claim–evidence 拆解。
- `nature-statistics`：实验单位、统计推断和报告审查。
- `nature-experiment-log`：实验原始记录和研究溯源。
- `nature-reviewer`：论文证据链已经形成后的独立审稿压力测试。
- `nature-writing` / `nature-figure`：科学决策稳定后的论文叙事和主图生产。
