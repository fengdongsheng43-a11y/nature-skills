# Provincial science fund: review gates

| Gate | Specific challenge | Output/decision |
|---|---|---|
| L0 Policy | 谁资助？哪个省份/年度/类别？资格、名额、系统+校内时点？ | BLOCK or VERIFY |
| L1 Science | 是否仍是一个可证伪的自然科学问题？ | SCIENCE PASS/REFRAME |
| L2 Nearest prior art | 是否只是把已有研究换到本地场景？ | NOVELTY NARROW |
| L3 Local boundary | 区域问题是否具有实测条件、而非地名修饰？官方是否要求该关联？ | REGION FIT |
| L4 Serious rival | 温度/盐分/群落组成/传质/测量偏差等竞争解释是否可区分？ | P0 RE-DESIGN |
| L5 Scope | 经费/期限/样品/设备与任务匹配？博士项目是否独立且最小充分？ | DOWNSCOPE |
| L6 Prior foundations | 现有数据属于谁？是否跨项目偷换证据、重复申报/重复资助？ | OVERLAP BLOCK |
| L7 Written claims | 假说、拟达到效果和已有结果明确分开？申报模板/伦理/AI要求是否核对？ | CLAIM DOWNGRADE |
| L8 Submission | 单位审核、推荐/排序、系统提交、附件是否各自完成？ | SUBMIT READY / BLOCKED |

输出按 `P0重大问题 / P1重要完善 / P2编辑润色` 划分，最多五条决定性问题，每条写 named rival、修复动作、证据等级、是否允许继续。
评审评分仅能作为内部排错辅助；不得声称真实评委身份或成功概率。
