# nature-provincial-fund-proposal — 省/自治区/直辖市自然科学基金

## 定位与不可违反的边界

**地方自然科学基金不是“简化版国自然”**；不同省份和同一省份的不同项目类别、年度，申请资格、指南方向、重点任务、预算、期限、推荐名额、申报系统与考核差异可能很大。
- 省/自治区/直辖市基金主管部门是地方科技管理机构时，使用本 Skill；**国家自然科学基金的“地区科学基金”应改路由 `nature-nsfc-proposal`**。
- 科学问题与证据真伪仍由**本 fork** `skills/nature-research-partner/SKILL.md` 主导，不允许本 Skill 把地方需求自动升级成机制创新。
- 申报论证文字与质量检查交给本 fork `skills/nature-proposal-writer/SKILL.md`；政策/地方适配由本 Skill 处理。
- 中国地方项目的 AI 使用、模板、伦理和学术诚信具体限制以**当年当地官方规定**为准；绝不假设 NSFC 的全部条款自动适用；无论何处都禁止虚构数据和参考文献。
- 不为迎合地方主题而改变现有观察、编造“内蒙古特色”或跨项目搬运前期数据。

## 路由与版本
官方规则优先级：**当年省/自治区/直辖市科技厅（委）正式申请指南及附件、申报系统真实模板 > 当年地方项目管理办法/官方通知 > 主管部门/依托单位正式推荐和内部流程 > 已核实的往年文件 > 第三方 Skill**。
新年度指南来自用户上传、官方官网或可核对的原件；无法访问时记录 `UNKNOWN`。不能从其他省份推断限页、比例、人才类别或地方优先方向。
只有当官方项目类别/指南确实强调区域需求时，才提高地方关联性权重；**一般面上类基础研究不被自动要求产业转化或内蒙古样品**。
更换省份、年份或资助类别必须新建 `FUND_PROFILE`；具体格式见 `references/annual-guide-intake.md`。

## 模式

- `explore`：从当地未解科学问题/可研究的真实区域差异切入；
- `challenge`：审查“地方特色≈创新点”之类的弱论证、既有工作重复和最强竞争解释；
- `design`：构建有限预算与期限内的最小充分实验；
- `revise/update`：新指南、新政策、新数据或已有草稿更新。
区自然的研究目标不是默认比国自然科学标准低，而是**项目类别和资源约束不同**。

## P0 — Official call & institutional routing（优先门槛）

锁定：`province/region`、主管单位、申报年度、项目类型/亚类、申请人阶段/资格、推荐名额与校内选拔、是否限项、指南主题、依托单位、校内与系统截止、资助方式、项目期限、经费预算/报销约束、绩效要求、伦理、科技诚信、是否可能与其他课题构成重复申报。
- 人才类博士项目和省级面上、重点、联合不能使用同一套默认“合理任务数”。
- 校内限额、推荐与官方系统截止是**不同概念**；有校内前置选拔时先确认参与资格和内部截止。
- 需要真实政策才能做资格、经费限额、期限、验收指标等确定性结论；无源则阻断相应判断，不阻断可独立进行的科研审查。
- 记录具体文件、链接、页码/条文、获取日期及解释争议（见 `references/annual-guide-intake.md`）。
**产出**：`FUND_PROFILE.md`、`RULE_LEDGER.md`、`GUIDE_FIT_MAP.md`、`INTERNAL_NOMINATION_CHECK.md`（若适用）。

## P1 — 科学问题独立于地方叙事

先按 `nature-research-partner` 冻结观察/解释/假设/机制/预测/证据/主张/决策、测量与实验单位。提出真实 scientific contradiction（科学矛盾）。
检查三个容易混淆的层次：
1. **真实地区条件**（实测低温、盐分梯度、地质背景、污水水质等）；
2. **现有方法在此边界下的机制缺口**（与最强既有方法比，究竟哪一步不明）；
3. **待检验的新知识**（为什么这个条件能成为机制识别场景，而不是换地区重复实验）。
“本地区极端温度”“本地首个”“首次在某地区检测”不能独立构成科学创新。

## P2 — 文献门槛与对立假设

与国自然一样必须通过五轮 literature-evidence gate：Landscape / Nearest prior art-SOTA / Mechanism+method / Counter-evidence / Publication anchor，记录全文/摘要/元数据核验与证据距离 A–E。
对 candidate gap 做 `Recurring ∩ Unresolved ∩ Important ∩ Tractable` 交集审查。主假设必须有**严肃竞争解释 + 区分性预测 + 死亡条件**。
仅讨论应用效益而不验证关键机制时，应明示科学目标已不足，建议重新定位项目类型，不用漂亮文字掩盖。

## P3 — Dual fit（科学成立 × 地方/项目类别适配）

科学价值和地方适配分别打标签，不能互相替代：
- `SCIENTIFIC`：可证伪科学问题、边界内新机制/新关系/新方法证据；
- `REGIONAL`：地区实测条件、区域独特的样本/处理场景或经指南核验的需求；
- `SCHEME`：该年度该类别支持何种研究、哪些能力/成果为硬性要求；
- `FEASIBILITY`：样本、仪器、人数、期限、预算、合作权限。
项目归类判断：基础科学优先、需求牵引基础研究、明确专项导向，具体取决于当年指南而非固定评分权重。
**项目边界审查**：博士论文/导师项目/企业课题与本基金的任务、数据、经费、负责范围、创新性增量逐条对照。合规共用资源允许与否依官方规定，不得隐瞒重复研究。

## P4 — Minimal sufficient work packages（最小充分研究任务）

用 `Challenge → Scientific motivation → Mechanism → Prediction → Experiment → Measurement → Statistical test → Decision rule → Claim` 建证据架构。
- **P0 实验**：最便宜、能改变中心结论或排除最强竞争解释的试验；优先核对测量有效性。
- **P1**：机制深化、环境扰动稳定性与关键稳健性；
- **P2**：可选扩展/外推/增补表征，不写作未经评估的必交承诺。
每个 work package 必须列：目标、实验单位、对照、关键测量、预期不同结果、负结果应对、成本/周期/样品、阶段验收里程碑。
只有当目标属于指南支持、研究规模与经费期限相称，才能进入正式文本组织。不要因“想发高水平期刊”而堆砌 WGS/组学/模型/中试等未必必要的技术。
**产出**：`AIM_EVIDENCE_MATRIX.md`、`DECISIVE_TEST_MATRIX.md`、`MILESTONES_AND_BUDGET.md`、`OVERLAP_BOUNDARY.md`。

## P5 — 申报论证与作者审定

调用 `nature-proposal-writer` 建 `research_canon / evidence_table / argument_map / section_contracts`；只按**该省该年度该类别官方模板**组织章节。
申请人主导科学观点与正式提交，辅助以科学证据审查、文字反馈、例句和可追溯的修改建议；不得把科研设想/待测值包装为前期结果。
对立项依据、研究内容、研究基础均设置 allowed/forbidden claims；前期基础只用相关且真实的材料，实验未完成只能写拟开展。

## P6 — Local panel review & output

按 `references/reviewer-gates.md` 启动四视角：
- 科学评审：假说、现状、竞争解释、测量能否支撑结论；
- 领域评审：区域条件是否构成真实研究边界，而非地名装饰；
- 可行性评审：地方项目规模下 P0 是否能完成、经费与里程碑是否可信；
- 依托单位审核：资格、名额、导师/合作、附件、科研诚信、系统与校内时间。
输出 Major concerns（最多五个决定性缺陷）、能够修改与应删除主张、是否值得继续申报。不能保证通过率。

## P7 — 当年指南替换与长期状态

当用户发来新指南：提取政策 `RULE_LEDGER` → 与旧年逐条差异对比 `POLICY_DIFF` → 更新类别/章节/资格/预算/截止/验收要求 → 重跑 P0 与 P3/P4/P6 中受到影响的节点。**保留**科学文献/实验事实和被拒绝假设的历史，不因为申报口径变化而改写科学结论。
对新年度的不适用细则标 `SUPERSEDED`；没有核验结果不得标 `VERIFIED`。

## 停止或降级
不符资格/名额 → 不推进正式申报；指南方向不符 → 换类别或停止；地区事实未核实 → 不能写地方独特性；最近似研究覆盖全部科学增量 → 重新提出问题；核心实验超过预算/期限 → 缩小承诺；竞争假设不可区分 → 降级机制主张。
参考 `references/annual-guide-intake.md`、`references/reviewer-gates.md`、`docs/funding-workflow-architecture.md`。
