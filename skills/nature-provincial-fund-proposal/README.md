# nature-provincial-fund-proposal

省、自治区、直辖市自然科学基金专用科研论证与申报适配（Draft v0.1.0）。支持“省自然”“区自然”“内蒙古自治区自然科学基金”“自治区博士研究生项目”等。

并不认为地方基金科学要求更低；与 [nature-research-partner](../nature-research-partner/SKILL.md) 共用科研证据门槛，额外验证地方项目类别、真实区域边界、校内推荐和有限资金规模。申请书辅助由 [nature-proposal-writer](../nature-proposal-writer/SKILL.md) 管理。

**注意**：国自然“地区科学基金项目”使用 [nature-nsfc-proposal](../nature-nsfc-proposal/SKILL.md)，不是本 Skill。

**例句**：「按 nature-provincial-fund-proposal 审查2027内蒙古自治区博士研究生自然科学基金方向；先提取我上传的官方指南并核实与博士论文是否重复，然后提出 P0 决定性实验。」
