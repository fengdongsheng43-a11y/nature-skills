# nature-nsfc-proposal

国家自然科学基金（NSFC）专用**选题—证据—研究设计—论证—评审与合规**工作流（Draft v0.1.0）。

本 Skill **不替代** [nature-research-partner](../nature-research-partner/SKILL.md) 的科研决策规则；以 [nature-proposal-writer](../nature-proposal-writer/SKILL.md) 处理论证与稿件反馈。重点是年度官方政策、NSFC 类别识别、申请代码、可验证科学增量、 P0 决定性实验、结构与材料合规。

**路由**：国自然（包括国自然*地区科学基金*）使用本 Skill。省、自治区、直辖市科学基金使用 [nature-provincial-fund-proposal](../nature-provincial-fund-proposal/SKILL.md)。

**例句**：「按 nature-nsfc-proposal 审查我的2027年国自然青年基金选题，先核验指南类别和前期数据，再看创新与决定性实验。」

入口：[SKILL.md](SKILL.md) · [年度政策核验](references/annual-guide-intake.md) · [评审门槛](references/reviewer-gates.md) · [双流程架构](../../docs/funding-workflow-architecture.md)。

官方政策每年更新，本 Skill 不提供未经核验的定额或通过率；2026 NSFC 禁止直接使用生成式 AI 生成申请书，最终责任属于申请人。
