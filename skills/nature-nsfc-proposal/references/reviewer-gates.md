# NSFC reviewer and claim gates

| Gate | Reviewer challenge | Evidence needed | Outcome |
|---|---|---|---|
| G0 官方资格 | 申请人/单位/限项/类别/代码/年度是否正确？ | 当年指南+依托单位材料 | BLOCK / VERIFY |
| G1 科学问题 | 是否存在可验证的、非措辞性的科学矛盾？ | 基线和观察 | CONTINUE / REFRAME |
| G2 现状创新 | 最近似研究已经做到哪里，剩下的增量是什么？ | 五类文献锚点/专门查新 | NARROW / CONTINUE |
| G3 机制判别 | 若竞争假设成立，哪项结果会不同？ | H1/H2、死亡条件、决定性实验 | BLOCK CAUSAL CLAIM |
| G4 核心实验 | 实验单位/对照/测量是否有效，P0是否可实施？ | 决定性实验与预算时间 | RE-DESIGN |
| G5 研究基础 | 已有数据是否直接证明申请人有能力完成关键步骤？ | 真实成果/条件/限制 | MITIGATE |
| G6 任务映射 | 科学目标→研究内容→实验→预期证据有无断链？ | AIM_EVIDENCE_MATRIX | RESTRUCTURE |
| G7 提交诚信 | 文献/图表/个人贡献/AI披露/伦理/重叠是否真实合规？ | 原始资料及官方要求 | BLOCK SUBMISSION |

默认输出：最多五项决定成败的 Major concern（严重问题）+ 支持与反证 + 修复动作 + 当前可支持措辞 + 继续/收缩/搁置决定。
评分不是基金委评审成绩；不得编造概率、命中率或无法校准的创新分数。
